## 已确定的设计方向

1. 普通问答的第一条主模型请求不自动附加 baseline 本地正文，由主模型直接回答或调用现有工具；不新增必经的独立意图分类模型。
2. 先复用 Qwen Embedding 检索产生的原始 cosine、现有候选选择和上下文投影。相关性门槛须经过当前 embedding profile 和语料的独立评测，不能直接使用任意经验常数。
3. 允许“检索有候选，但没有正文通过准入”。这既不是服务错误，也不等于资料库中没有答案。
4. 首版只处理新进入模型视图、身份可信的本地检索正文。保留原始检索 API、trace、证据 ledger 和显式原文读取语义。
5. 同一有效上下文中的旧正文不逐轮重选；话题切换后彻底清除历史正文另作扩展。首版承诺的是避免不必要的新预取与新正文注入，不是每次请求都没有历史无关文本。
6. 新行为先显式启用并做对照；未通过验收不改变产品默认。现有 Jev 的自配置、证据判断职责和 single/progressive 输出合同不能因简化首问而被顺带破坏。

## SDD 执行规则

`FR-*` 是功能要求，`NFR-*` 是质量与运行约束，`T-*` 是任务，`AC-*` 是验收场景。每项功能必须能追溯到任务、测试和证据。

实现改变行为、覆盖面或发布门槛时，先更新对应规格和验收；不要以改测试来掩盖需求退化。校准集、验证集和保留测试集按问题家族和文档划分，不能在看过保留集后调阈值。

以下是必须关闭的工程决策，不是可以随意填写的空项：相关性阈值、支持的校准分组、混合分数缺失策略验证、配置兼容性、真实模型质量与缓存收益。任务表说明每项由哪一步解决。

后续实现仍遵守 [AGENTS.md](../../AGENTS.md)；新增运行时依赖、embedding 后端或许可变化需要原有审批。本规格不要求这些变化。共享 `~/.autorag`、其他会话进程和原生数据源不能作为 QA 的可写状态。

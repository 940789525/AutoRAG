# 增量论文研读收件箱 MVP

将新导入的论文转化为围绕研究问题的阅读建议，附带与库内旧文献的比较和可核验依据。论文原文通常不变；业务事件是新文件进入资料库，而不是已有论文修改。

方案日期：2026 年 10 月 28 日。已实现 HTTP/SSE MVP，并补齐开发容器的一键组合调试和 TUI `/research` 收件箱入口。开始体验请先读 [TUI使用说明.md](TUI使用说明.md)。原始方案文件保留为设计依据。

## 核心决策

- 单用户、单本地论文库、PDF 优先；第一次扫描只登记存量，不自动深读全库。
- 监听只是发现线索；数据库处理记录与补偿扫描共同保证不遗漏导入。
- 以文件 SHA256 做确定性去重；DOI 和 arXiv 标识辅助关联论文，版本不自动合并。
- 研读按研究主题进行，比较基线固定为导入批次开始前已就绪的论文集合。
- 服务使用 TypeScript、Node.js、Fastify、PostgreSQL 和 DBOS，复用现有 Pi、解析、LanceDB 检索和本地 MinSync 嵌入。
- PostgreSQL 管研究元数据与任务；LanceDB 管检索；原始 PDF 留在原位置。服务为显式启用的可选模式。
- 第一个可使用版本通过 HTTP JSON 与 SSE 提供收件箱能力，不另建完整前端；可以通过 HTTP 客户端演示。
- 只承诺阶段恢复。中断的模型请求可能重试并再次计费，不承诺外部操作恰好执行一次。

# TUI 索引意图分流 · SDD

**最终决策**：明确命令沿用原入口；自然语言命中“索引”等现有候选信号时，用当前会话模型判断一次。只有用户明确要求执行索引操作，才把请求交给操作流程。询问、分类失败或仅被判为查询状态的自然语言候选，都将**完整原话**交回正常问答。取消和被新输入取代的旧请求直接结束。

例如，“当前有哪些文件，这些文件是否都已建立索引？”和“当前本地资料库中有哪些内容，资料库是否都已完成索引建立？”应查到同一份文件清单和覆盖情况。“帮我建立索引”仍走原有任务流程。

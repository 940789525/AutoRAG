# 实现与验证记录

日期：2026 年 11 月 2 日。代码基于当前本地 `codex/observable-local-index` 工作区；远端 fetch 因网络无响应限时退出，不能宣称已同步最新 origin/main。本次保留原有 1030 未提交文档改动，不更改日常配置或重启容器。

## 实际实现

- `src/agent/index-intent.ts`：完整句式快速路径、候选门控、严格结构化输出校验、一次语义识别、单项待澄清请求、状态计划、取消和迟到结果失效。
- `src/agent/agent.ts`：在检索之前接入路由，复用当前聊天模型及认证；直接分发已验证的内部任务；记录本轮提交的任务 ID，防止取消其他会话任务。普通问答继续原来的 steering/follow-up 行为。
- `src/agent/pi-session.ts`：支持异步输入处理，并保留来源，远程扩展消息不能授予本地索引写权限。
- `src/agent/index-controls.ts`：兼容分类函数不再使用旧的粗正则；原生模型工具仅允许状态查询，写请求由 TUI 路由执行。显式命令使旧的澄清和识别结果失效。
- `src/agent/query-decomposition.ts`：复用现有无工具 completion 适配，支持限制输出和记录用量；原有问题拆分默认行为不变。
- `src/agent/search-documents.ts`：补充索引意图诊断类型。
- `docs/embedding-setup.md`：更新用户入口说明。

明确自然语言不调用模型，例如“建索引”“请重建当前索引”“更新当前索引”“查看索引进度”。带模型选择或复杂限制的表述进入候选，最多一次应用层识别，输出上限 512 tokens，12 秒超时并支持取消。底层提供方的重试策略不等于应用层多轮识别。

首次 ensure_index 选择配置默认 profile；有兼容活动索引时沿用活动 profile 并 refresh；明确重建始终 build。局部范围、未知 profile、限制冲突、无索引时仅请求 refresh、跨会话取消均不擅自执行。普通问题和状态查询不启动 embedding 服务。分块与向量缓存继续由现有管线判断，未增加跨 generation 缓存。

组合请求首版澄清拆分，不自动执行前半句。无对话模型时，完整明确句式仍可执行；复杂候选显示模型不可用原因与 `/index` 指引。已有 Jev 配置不被本实现修改。

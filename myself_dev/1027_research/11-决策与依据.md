# 决策与依据

## 已确定决策

| 决策 | 结论 | 原因 |
| --- | --- | --- |
| 产品 | 论文比较、证据审阅与研究决策工作台 | 服务真实研究整理任务，与即时问答形成清晰分工 |
| 隔离 | 独立工程、API/Worker/数据库与配置 | 控制代码、故障和运行状态影响 |
| 主系统整合 | 首版不调用主 RAG，不修改其核心链路 | 避免研究需求迫使通用问答改变 |
| 来源 | 单个受信本地 PDF 库，只读使用 | 不迁移或改写用户原文 |
| 首次使用 | 选中少量论文后按需解析 | 不以全库向量化阻塞体验 |
| 持久流程 | 复用 DBOS 思路，业务状态独立于 Pi | 恢复和人工成果各有所有权 |
| 交互 | 比较矩阵、证据面板、备忘录与任务状态 | 便于核验、修正与现场展示 |
| 增量 | 用户显式加入资料，更新受影响事实与决策 | 不依赖静态论文经常修改 |
| 算法 | 有界单 Agent/阶段化流程先行 | 控制成本和可解释性，暂不做默认多 Agent 扇出 |
| 质量 | 机械验证、语义支持、可比性分别评估 | 不把引用存在等同于结论正确 |

## 规格变更规则

本目录是新版指导基线；原 `/workspace/myself_dev/1027` 是旧收件箱方案，不因文件名相似就合并其启动、索引和表结构。前两份调研说明作为背景，若与本目录更具体的契约不同，以新版统一修订后的规格为准。

优先遵循用户当前授权与有效仓库指令，再落实本目录需求和契约。文档之间出现实质冲突时，记录决策并同时修正需求、接口、模型、任务和测试，不让实现自行选择一份忽略另一份。

变更记录字段：changeId、日期、原规则、新规则、原因、影响的 FR/NFR、契约版本、迁移与验证、授权依据。增加默认远端处理、主系统依赖、自动执行或协作能力均属于范围变化，不能当作普通实现细节。

## 参考资料

以下来源用于架构和方法参考，读取日期为 2026-10-28；不是对当前锁定 SDK 的兼容性背书，也不是对本项目效果的实测。

- [Pi SDK](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sdk.md)：嵌入会话、显式资源、工具、事件与生命周期。

- [oh-my-pi](https://github.com/can1357/oh-my-pi)：结构化任务成果、活动与用量可视；不迁用工作树或完整 IDE 工具面。
- [DBOS Queue Worker 文档](https://docs.dbos.dev/typescript/examples/queue-worker) 与 [示例代码](https://github.com/dbos-inc/dbos-demo-apps/tree/main/typescript/queue-worker)：API 与持久 Worker 的进程边界。
- [DBOS 工作流管理](https://docs.dbos.dev/typescript/tutorials/workflow-management)：取消与正在执行 step 的语义差别，接口需匹配版本。
- [Docker 资源约束](https://docs.docker.com/engine/containers/resource_constraints/)：容器默认不限资源、硬上限与软权重的区别。
- [Open Paper](https://github.com/khoj-ai/openpaper) 与 [开发说明](https://github.com/khoj-ai/openpaper/blob/master/DEVELOPMENT.md)：原文对照、项目表格及前端/API/任务分离；不照搬云服务和 Celery 全栈。
- [ResearchQA](https://arxiv.org/abs/2607.11074) 与 [评测实现](https://github.com/khoj-ai/openpaper/tree/master/server/evals)：引用可验证性和语义质量分开测量。
- [PaperQA2，2024](https://arxiv.org/abs/2409.13740)、[OpenScholar，2024 预印本](https://arxiv.org/abs/2411.14199)：阶段化证据收集、引用和文献综合评测。
- [Optimist Deep Research，2026-10 预印本](https://arxiv.org/abs/2610.23299)：显式研究状态与缺口驱动，案例不代表普适优势。

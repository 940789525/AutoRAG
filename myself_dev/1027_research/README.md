# 新版 Research 开发文档

本目录使用 SDD（Spec Driven Development，规格驱动开发）组织需求、契约、任务和验收，并以 MVP 分阶段交付。它是后续实现的指导基线，不是已经完成的功能说明。

**产品目标：**独立运行的本地论文研究工作台，支持跨论文证据矩阵、人工审阅、比较条件核验和可追溯的决策备忘录。

**首要约束：**新版 Research 与 AutoRAG 的代码、依赖、状态、启动和部署隔离；首版只共享只读论文来源，不调用主 RAG 完成研究任务。

## 使用方式

先阅读 00、01、02，再按 07 执行。每项任务同时落实 03—06 的契约，并用 08 验收。修改规格时先更新受影响的契约与追踪关系，不直接改变业务语义。

当前版本为 `research-spec-v1.1`，日期为 2026-10-28，状态为“开发规格草案”。本目录没有实现代码、可执行迁移或已通过的功能验收记录。后续“基于这些文档开始开发”的授权不等于功能已经完成，也不自动扩大到主系统改造。

v1.1 补齐精确历史矩阵、比较范围、备忘录修订边界、成功重跑、项目输入切换、比较失效、阶段成果去重、人工补证、阅读覆盖校验及定稿并发保护；对应变更记录见 11，新增验收为 AC-20—26。T-00 可开始；首个迁移和 API schema 必须落实这些契约后再冻结，不把兼容性实验的未执行状态改成通过。

### 参考集与硬门槛

首版使用至少 12 份合成文档，覆盖 A01–A03 的核心家族；按文档家族拆分开发集与保留验收集，不能只在同一表上修改分数后当成独立保留集。分开评测原生表和扫描表。

- 分别记录字符识别、单元格文本、字段对应关系、目标记录召回／全量覆盖和最终回答准确性；不能用 CER、任务 succeeded 或整体平均分替代表格关系正确率。
- 核心合成成绩表及保留验收集中的目标字段对应必须全部正确，全量问题目标记录召回 100%；不确定项必须明确说明，不能凭猜测通过。其他表格按家族报告，不用平均值掩盖退化。
- 来源、版本、权限、token 上限、分页完整性、取消回收和离线边界是硬门槛。资源探针在声明的容器上限内不得 OOM，不能通过放宽容器内存来声称适配当前配置。
- 延迟不预先编造每页秒数：记录完整单份耗时、每页耗时分布、模型冷启动与预热差异及超时数。达到现有文件期限前处理不完则说明该规模不满足门槛；调整期限前先修订规格并披露代价。
- 质量判定不以通用低置信阈值保证准确；保留原始 OCR 中间结果与表格位置，便于定位失败阶段。

## 隔离 QA 与检查

手动 QA 优先使用 [AGENTS.md](../../AGENTS.md) 的 Docker 入口，仅挂载本 clone，不挂载真实 home 或原生 datasource stores。无论 Docker 或 host，每次 CLI／AutoRAGAgent 调用前均设置任务临时 `HOME`、`AUTORAG_HOME`、`AUTORAG_CONFIG`、Pi agent 目录与模型缓存；写配置前核对路径属于任务目录。记录真实配置前后哈希；只清理自己的临时文件和进程。

确定性索引／检索测试禁用所有远端提供方；真实回答验收若使用远端，只用合成文档及已有可信授权。私人原件不进入自动测试、公共提交、Exa 查询或新服务。

实现阶段必须执行：

```bash
bun run check && bun run lint && bun run typecheck
```

另需覆盖变更的测试、build、新增运行时／许可证清单涉及的 `bun run supply-chain`，以及更新后的 live-E2E 冷暖验收。Python 解析协议使用独立锁定环境运行其契约测试；原 FastEmbed Python 契约仍需回归，不能因新解析器而失效。

记录至少包含：源码 SHA／工作区状态、依赖与模型清单哈希、解析配置指纹、参考集版本与分组、模型实际输入、原件／镜像／结构版本、每项 PASS／FAIL／未执行及理由、耗时／内存、配置哈希和清理回执。模型权重文件大小不能填入运行内存字段。

本轮文档交付仅检查文档内容、路径、相对链接与变更范围；不能把文档自检作为以上实现验收完成的证据。
